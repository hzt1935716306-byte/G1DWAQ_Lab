# PPO 探索、四模型固定上限对比（缩减版）

用户最终确认：不再让四模型一起逐档探索，不执行每格100次、不自动扩展补样本。仅PPO寻找共同测试范围，四模型每格20次、最多3个强度点。探索与比较分开；此阶段为小样本验证，不声称最终论文统计精度。

## 固定方法

沿用 `g1_paper_fixed_time_v1/checkpoint_identities.json` 的 PPO、DWAQ V3、Ours，及 `g1_paper_dwaq_v2_fixed_time_v1/checkpoint_identities.json` 的 DWAQ V2。均使用原固定最终checkpoint、训练种子42；PPO仍是 `g1_slope_nosys_d_matched`，不是新增的RL-only消融。

## 执行顺序和停止规则

1. 原坡度−10/0/+10°，0.5/1.0m/s，四方向0/90/180/270°，分别探索B1推力和B2速度突变。PPO每格20次，初始最大值分别0.9、2.5m/s，并有0.3、0.5m/s容易参考点。
2. 每个条件独立把幅值乘1.25。PPO在该条件恢复率≤30%或无有效受扰样本后停止加大。最多16档（含初始最大档）为执行预算护栏；未达到目标则明确“未找到上限”，不能称为测得极限。不会因为其他方法表现好继续加大。
3. 从PPO观测到的首次向下50%跨越区间线性定位一个中间测试点；没有跨越则取容易点与最大点的几何中点作为普通中间点，不冒称D50。
4. 冻结容易、中间、最大至多3点，四模型共享相同场景，每格20个独立正式种子。小样本曲线非单调或D50不明确则保留待确认，不自动加跑。
5. 完成原坡度对比后，新增−20/−15/+15/+20°：先四模型无扰动行走每坡度/速度20次，再重复上述流程。

原3坡度比较最多2880条/模型，四模型11520条；新增4坡度最多3840条/模型，四模型15360条；新增无扰动共640条。PPO探索另计，按条件达到停止规则后立即停止，不固定跑满。旧数据不重跑，不与新场景计数混合。

固定64个并行环境，每个模型按组连续运行，避免每个条件重复初始化仿真。代码/物理契约错误停止；跌倒、未恢复、受扰前失败均保存并继续。

## 判据及物理契约

复用 `g1_paper_recovery.Trial`，不修改判据：真实GT CoM heading XY速度误差≤0.2m/s，世界绝对roll/pitch≤15°，连续0.3s确认；B1撤力/B2施加速度变化后5s内确认，并存活正常完成12s。T/K均截至确认，失败主T/K为null。独立物理触地5N/3N滞回、2帧、0.08s去抖；需先离地，不要求交替，同时触地计2次。

B1保持0.2s、躯干CoM实际世界外力、沿初始行进方向坡面切向，F=m·Δv_eq/0.2；B2水平世界XY基座线速度相加，角速度不变。原actor历史及native context路径不改。固定课程地形、控制dt0.02s、物理dt0.005s。

新7坡度terrain及质量/物理hash跨四模型、全部波次一致。旧3坡度mesh与新mesh不同，因此旧结果保留为单独历史参考。训练配置最大tan(15°)，重建训练地形范围约−14.9325°至+14.9454°；±15°标注边界，±20°标注域外未见坡度。重建范围不证明实际训练访问。固定世界姿态15°门限不随坡度放宽。

## 种子与统计

phase、condition、repeat用互不重叠的uint32整数区间分配种子；同一条件/重复在各强度之间共享初态及随机3–5s施扰时刻，四模型逐场景配对；不同坡度种子不同，不宣称跨坡度逐初态配对。探索与正式种子严格不同。

恢复/生存条件分母为真正受扰数，同时列指定数和受扰前失败。无受扰分母为N/A；T/K仅成功恢复样本。D50仅在相同坡度、速度、方向、扰动类型下由实测跨越区间估计；未跨越给范围界限，非单调保持待确认。Wilson95%区间只反映评测采样，不代表训练种子不确定性。四模型只比较PPO选出的范围，不宣称找到其他方法真实极限。

原始trace/event/record全部保留，seal逐记录SHA验证，不进行全量trace重放。报告只纳入完成的整波次，探索只含PPO，固定对比必须四模型齐全。
